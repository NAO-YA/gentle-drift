# モジュール計画

## 目的

シンプルなランディングページの`Start`から、炎、竹、水面、雲、海藻、お香の煙、木漏れ日、花びら、ほたる、カーテンが薄黒の背景の中で穏やかにゆらゆらと動く鑑賞体験へ入るウェブアプリを作る。無料のブラウザ版に加え、同じ体験をWindowsのネイティブなスクリーンセーバーとしてGitHub Releasesから配布する。ログイン、決済、会員機能は実装しない。

## 段階的なリリース

1. **無料公開版**: ランディングページの`Start`から10種類のゆらぎを鑑賞できる。モチーフ、色合い、ゆらぎの強さは鑑賞ページで調整できる。背景は常に薄黒とし、目に優しい落ち着いた配色を用いる。ログインと決済は設けない。
2. **Windows版の公開**: 同じ描画をネイティブな`.scr`として配布し、GitHub READMEの写真と紹介文からブラウザ版・Windows版の体験を案内する。
3. **反応の確認**: 利用者の感想をもとに、好まれるモチーフや求められる体験を確認する。
4. **Pro版の検討**: 無料版で価値が確認できた後に、追加する体験、価格、アカウントの必要性、決済方法を決める。

## この段階で決めないこと

- Pro版で提供する具体的な機能
- 料金、プラン数、決済方法
- アカウントやクラウド保存の要否
- 保存、画像書き出し、作品ギャラリーの有無
- 紹介施策の有無

これらは無料公開版の反応を確認してから決める。未決定のPro版向け基盤は初期版に含めない。
