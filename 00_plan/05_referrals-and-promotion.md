# 05 紹介・プロモーション

## 位置付け

初期無料版では、紹介コード、割引、キャンペーンを実装しない。一方で、GitHubの公開READMEに紹介用の写真、Web版への導線、Windows版のダウンロード導線を用意し、作品の雰囲気と利用方法を分かりやすく伝える。無料公開版の利用者の反応を確認した後、Pro版の提供方法が決まった場合に紹介施策の必要性を検討する。

## 初期版の決定

- 紹介コードや招待URLを発行しない。
- 割引、無料期間特典、利用履歴の追跡を行わない。
- 紹介のための利用者データを保存しない。
- GitHub READMEで、暗く落ち着いた室内と月明かりの水面を用いた紹介写真を表示する。
- GitHub READMEから無料Web版とWindowsスクリーンセーバー版へ案内する。

## 将来の検討事項

- 紹介施策が利用者にとって自然で役立つか
- 特典の内容と適用条件
- 不正利用の防止と個人情報の取り扱い

紹介施策は、Pro版の内容と運用方針が決まるまで仕様化しない。
