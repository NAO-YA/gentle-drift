# 07 Windowsスクリーンセーバー

## 責務

ブラウザ版と共通のCanvas描画をWindowsのネイティブなスクリーンセーバーとして実行し、GitHub Releasesから配布する。

## 機能

- `.scr`として起動し、`/s`では接続済みのすべてのディスプレイを全画面で表示する。
- `/c`では、既存の`Scene`、`Palette`、`Amount`、`Motion`を操作できる通常ウィンドウを開く。
- `/p <HWND>`では、Windowsのスクリーンセーバー設定内にプレビューを埋め込む。
- スクリーンセーバー中のマウス移動またはキー入力で、鑑賞を終了して元の画面へ戻る。
- スクリーンセーバー中はWeb版のコントロールとモチーフ名を表示しない。

## 配布

- GitHubの公開リポジトリ`NAO-YA/gentle-drift`でソースと紹介用の写真を公開する。
- バージョンタグ`v*`のpushを契機にGitHub ActionsでWindows x64向けにビルドする。
- GitHub Releaseには`GentleDrift.scr`、隣接する`Web`フォルダ、インストール手順を含むZIPを添付する。
- GitHub上でソースは閲覧できるが、ライセンスはAll Rights Reservedとし、販売用バイナリ・素材の再配布を許可しない。

## 受け入れ条件

- Windowsのスクリーンセーバー設定からプレビュー、設定、全画面表示を行える。
- マルチモニター環境では全画面表示が各ディスプレイを覆う。
- スクリーンセーバーを終了すると、OSの画面を操作できる状態へ戻る。
- GitHub READMEに写真、Web版への導線、Windows版のダウンロード導線、インストール方法がある。
