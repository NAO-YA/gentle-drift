# 01 描画エンジン

## 責務

炎、竹、水面、雲、海藻、お香の煙、木漏れ日、花びら、ほたる、カーテンを画面全体に描き、静かで連続的なゆらぎを作る。背景は常に薄黒で統一し、目に優しい落ち着いた色合いを重ねる。描画はブラウザ内で完結し、鑑賞中に外部APIを呼ばない。

## 入力

| 設定 | 内容 | 初期値の例 |
| --- | --- | --- |
| `scene` | 描画する自然モチーフ | `flame` |
| `palette` | 色合い | `warm` |
| `amount` | モチーフを構成する要素の量 | モチーフごとの標準値 |
| `sway` | ゆらぎの強さ | `gentle` |
| `seed` | 同じ初期状態を再現する乱数の種 | 自動生成 |

`scene`は、形、配色候補、動く方向、ゆらぎ方をまとめた設定オブジェクトとする。

## 内部構成

```text
VisualEngine
├── SeededRandom       # seedから再現可能な乱数を出す
├── SceneRegistry      # 自然モチーフの定義を保持する
├── SceneFactory       # モチーフを構成する要素を生成する
├── Simulation         # 時間経過によるゆらぎを更新する
└── Renderer           # Canvasへ描画する
```

## 方針

- 初期版はCanvas 2Dで、自然なゆらぎの見た目を検証する。
- ReactなどのUI層は設定の保持だけを担当し、各要素の更新は`VisualEngine`内で行う。
- seedをURLのクエリに反映できる設計にする。例: `/?seed=abc123&scene=flame`。
- 明滅や急激な変形は避け、落ち着いて眺められる変化を優先する。

## 初期モチーフ

| ID | 方向性 |
| --- | --- |
| `flame` | 暖色の炎が上へ伸びながら、ゆっくり形を変える |
| `bamboo` | 竹の幹と葉が風に合わせて静かに揺れる |
| `water` | 水面の波紋や反射がなめらかに広がる |
| `cloud` | 淡い雲がゆっくり流れ、輪郭がやわらかく変わる |
| `seaweed` | 海藻が水の流れに合わせて左右にたゆたう |
| `smoke` | お香の煙が細く立ち上り、やわらかくほどける |
| `sunlight` | 木漏れ日が葉の影とともに静かに移ろう |
| `petals` | 花びらがゆっくり舞い落ちる |
| `fireflies` | ほたるの小さな光が静かに漂い、やわらかく明滅する |
| `curtain` | 薄いカーテンが風に合わせてゆるやかに揺れる |

## 受け入れ条件

- モチーフ、色合い、要素の量、ゆらぎの強さを変更できる。
- 再生成時に配置や形の違いを楽しめる。
- 同じseedと設定で、同じ初期状態を再現できる。
- 画面サイズ変更後も全画面描画を維持する。
- `prefers-reduced-motion`が有効な環境では、動きを抑えられる。
- 10種類のモチーフで、それぞれの自然なゆらぎが視覚的に判別できる。
- どのモチーフでも背景は薄黒で統一され、急な点滅や強い原色を使わない。
