# 06 鑑賞体験・品質

## 鑑賞体験

- 炎、竹、水面、雲、海藻、お香の煙、木漏れ日、花びら、ほたる、カーテンの動きは、穏やかで連続したゆらぎとして感じられることを優先する。
- 背景は薄黒で統一し、すべてのモチーフに目に優しい落ち着いた色を用いる。
- 急な点滅や強すぎる色の変化を避け、長く眺めても落ち着ける見た目にする。
- 画面サイズが変わっても、モチーフを自然に鑑賞できるレイアウトを保つ。
- デスクトップの操作パネルは、マウスを動かした時だけ現れ、鑑賞を妨げない。

## アクセシビリティ

- 設定ボタンに文字ラベルと`aria-label`を付ける。
- キーボードだけで設定を変更できる。
- `prefers-reduced-motion`では、静止画または動きを抑えた表示へ切り替える。
- 色だけに依存せず、モチーフと色合いには名前を表示する。

## テスト

- モチーフ、色合い、ゆらぎ、seed生成をユニットテストする。
- 10種類すべてのモチーフで、意図した自然なゆらぎと薄黒背景での見やすさを確認する。
- ランディングページの`Start`が、水面・Moonlightの設定で鑑賞ページを開くことを確認する。
- ランディングページと鑑賞ページで、薄黒の背景とセージグリーンのアクセントが一貫していることを確認する。
- 画面サイズの変更、マウス移動時のパネル表示、モバイル操作、キーボード操作、`prefers-reduced-motion`を確認する。
- `localStorage`に保存した設定が次回表示で復元されることを確認する。
- Windows版で`/s`、`/c`、`/p <HWND>`を実行し、全画面・設定・プレビューの各挙動を確認する。
- Windows版で、マウス移動とキー入力がスクリーンセーバーを終了させること、複数ディスプレイを覆うことを確認する。
- GitHub ActionsでWindows x64向けのRelease ZIPをビルドし、`GentleDrift.scr`と`Web`フォルダが同梱されることを確認する。

## 公開前チェック

- 初期版にログイン、決済、Pro版への導線が含まれていない。
- 10種類すべてのモチーフを選択できる。
- ランディングページに英語の`Start`だけが表示される。
- モチーフ名と設定の状態が分かりやすく表示される。
- 利用者に関する情報をサーバーへ送信しない。
