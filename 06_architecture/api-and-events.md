# APIとイベント設計

## 初期無料版

初期版は外部APIを持たず、ネットワーク経由で利用者情報、設定、決済情報を送受信しない。

画面内では、次の操作を`VisualEngine`へ反映する。

| 操作 | 内容 |
| --- | --- |
| モチーフの選択 | 炎、竹、水面、雲などの描画を切り替える |
| 色合いの選択 | モチーフの雰囲気を切り替える |
| 量・ゆらぎの変更 | 描画する要素と動き方を更新する |
| 再生成 | 新しいseedで初期状態を作り直す |

各設定の変更後は`localStorage`を更新する。URLにseedとモチーフが指定されている場合は、その値を優先して表示する。

ランディングページの`Start`は、`scene=water`、`palette=moon`、`amount=14`、`sway=1`をURLクエリとして鑑賞ページへ渡す。鑑賞ページはその値を初期表示に用いる。

## 将来のPro版

外部APIが必要になった場合は、提供するPro版の体験と扱う利用者データを決めた後に設計する。初期版のために認証、決済、会員、紹介用のエンドポイントは作らない。
